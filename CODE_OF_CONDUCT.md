# Code of Conduct · Правила общения

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive — no harassment, insults or personal attacks in issues, pull requests or any other project space.
Коротко: уважительно и по делу, без оскорблений и травли.

Report unacceptable behavior privately via **Security → Report a vulnerability** (start the title with "Conduct:"). Reports are handled confidentially. Maintainers may remove comments and block participants who break these rules.
